# موقع ذكريات MEIS Seniors

موقع من كذا صفحة (الرئيسية، Gallery، Little Us، Trips، Memories، The Crew). الصور بتتضاف بمجرد ما تحطها في الفولدر الصح، من غير ما تلمس أي كود.

## 1) النشر على GitHub (مجاني، مرة واحدة بس، من الكمبيوتر)

1. اعمل حساب على github.com، وبعدين **New repository**.
   - الاسم: قصير ومن غير مسافات، مثلاً `meis-seniors`. **مهم:** الاسم ده بيبقى جزء من اللينك، فمتغيرهوش بعد ما تطبع الـ QR.
   - اختار **Public**.
2. جوه الريبو: **Add file ← Upload files**، واسحب كل اللي جوه فولدر المشروع (الملفات والفولدرات: `index.html`، `css`، `js`، `data`، `images`، `scripts`، `.github`...) واضغط **Commit changes**.
3. اتأكد إن الملف `.github/workflows/deploy.yml` موجود. لو مش ظاهر (بعض الأجهزة بتخفي الفولدرات اللي بتبدأ بنقطة):
   **Add file ← Create new file**، اكتب في خانة الاسم `.github/workflows/deploy.yml`، والصق جواه محتوى الملف `deploy-workflow.yml`، وبعدين Commit.
4. **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
5. افتح تبويب **Actions** واستنى العلامة الخضرا (من دقيقة لـ 3). اللينك بتاعك:
   `https://اسم-حسابك.github.io/اسم-الريبو/`

## 2) فين أحط الصور

| الفولدر | يعمل إيه | التسمية |
|---|---|---|
| `images/cover` | الصورة الكبيرة في أول الصفحة الرئيسية | أول صورة في الفولدر (مثلاً `group.jpg`) |
| `images/gallery` | صفحة Gallery | اعمل فولدر فرعي لكل ألبوم: `images/gallery/Graduation-Rehearsal/` |
| `images/kids` | Little Us (كارت بيتقلب) | `ahmed-ali-then.jpg` (وهو صغير) و `ahmed-ali-now.jpg` (دلوقتي) |
| `images/trips` | صفحة Trips | فولدر لكل رحلة: `2026-03-12_Sharm-Trip` (التاريخ، شرطة سفلية، الاسم) |
| `images/memories` | حيطة الذكريات | اسم الملف هو التعليق: `last-bus-home.jpg` |
| `images/members` | The Crew | اسم الملف هو الاسم: `ahmed-ali.jpg` |

- لو عايز ترتب يدوياً، حط رقم قبل الاسم: `01-ahmed-ali.jpg`، والرقم مش هيظهر.
- التاريخ ممكن يبقى شهر بس: `2025-11_Alexandria-Day`.
- الصور الكبيرة (من الموبايل) بتتصغر أوتوماتيك وانت بترفع، مش لازم تصغرها بنفسك.
- ملفات iPhone من نوع **HEIC** مش بتظهر في المتصفحات. صورها JPG الأول.

## 3) إضافة صور بعد كده

من الكمبيوتر أو من متصفح الموبايل (Desktop site): افتح الفولدر في GitHub ← **Add file ← Upload files** ← **Commit**. بعد دقيقتين تلاقيها على الموقع، واللينك والـ QR زي ما هم.
فولدر رحلة جديد: **Add file ← Create new file** واكتب `images/trips/2026-05-02_Prom/note.txt` (ده بيعمل الفولدر)، وبعدين ارفع الصور جواه.

## 4) تعديل الكلام (`data/info.json`)

افتح الملف على GitHub واضغط أيقونة القلم. هنا بتحط: سنة الدفعة، جملة الغلاف، تاريخ التخرج (للعداد التنازلي)، رقم واتساب (زرار "ابعت صورة")، أغنية الدفعة، وصف الرحلات (المكان والحكاية)، والاقتباسات والقفشات. الأمثلة موجودة في الملف نفسه تحت أسماء بتبدأ بـ `_`. خلي بالك من الفواصل والأقواس.

## 5) الـ QR والهودي

- اعمل الـ QR **بعد** ما اللينك يستقر، من أي مولد مجاني (مثل qrcode-monkey.com) وحمله **SVG أو PNG كبير**.
- الطباعة: على الأقل 4×4 سم، أسود على أبيض بتباين عالي، وسيبه مساحة بيضا حواليه. جرب تطبع ورقة الأول وامسحها من كذا موبايل.
- اللينك الأقصر بيطلع QR أبسط وأسهل في المسح.

## ملاحظات

- الريبو Public، يعني أي حد معاه اللينك يقدر يشوف الموقع. الموقع مضبوط إن جوجل ما يفهرسوش، بس اسألوا الدفعة قبل نشر أي صورة شخصية.
- لو الموقع فتح فاضي أو الصور مش ظاهرة: شوف تبويب **Actions**، لو في علامة حمرا اضغط عليها وشوف الخطأ.
- لو عايز تجرب على جهازك: `python scripts/build_manifest.py` وبعدين `python -m http.server` وافتح `localhost:8000`.
